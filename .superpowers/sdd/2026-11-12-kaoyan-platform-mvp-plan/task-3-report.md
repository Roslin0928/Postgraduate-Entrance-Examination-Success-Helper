# Task 3：单词复习实现报告

## 完成内容

- 增加 `Word`、`UserWord`、`WordReview` 和 `VocabularyImport` 数据模型，并为账户、任务和复习记录建立关联。
- 复习调度支持不认识、模糊、认识三种反馈；按用户传入的 IANA 时区推进本地日历日期，认识后首次间隔 3 天，连续认识后间隔 7 天。不认识词会在当前复习轮次再次出现，并进入次日复习队列。
- CSV/TSV 解析支持 UTF-8 BOM、可选表头、引号字段、空行忽略、重复行报告及最大 1,000,000 字节限制。
- 增加词汇待复习、复习反馈、自定义词和导入 API。所有查询和写入均以认证账户为范围；复习时验证词为内置词或当前账户所有，并验证关联任务属于当前账户且类型为词汇。
- 增加 5 个内置考研词条作为可用起始词库；用户首次访问待复习接口时自动建立自己的复习状态，词条本身仍是共享内置数据。
- 待复习接口按需创建当日 `vocabulary` 任务并返回 `taskId`。英语词汇页提供数量、进度、卡片、反馈按钮和 CSV/TSV 文件导入；从今日任务进入时携带任务 ID，自由复习不关联任务。
- 今日任务页增加独立“英语学习 / 单词复习”入口；任务加载先访问待复习接口创建当天词汇任务，再读取同一任务数据，因此首次进入今日任务也能看到词汇任务卡。
- 为 API Jest 补充 `.test.ts` 匹配配置，并添加调度、解析和 API 隔离测试。
- 增加认证缺失、用户间词条隔离、非词汇任务关联拒绝的 API 覆盖测试。
